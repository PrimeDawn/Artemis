2. 手机端为什么不需要改

wire 兼容做法

sendState() 仍输出 {v:2,kind,sessionId,epoch:null}，epoch 键保留为 null。原因：android/app/src/main/java/io/github/primedawn/artemis/pairing/DeviceClient.kt:70 对键集合做严格校验，删键会让手机抛 E_PROTOCOL 断线。新增用例 waiting event keeps the epoch key for phone wire compatibility 守住这条。

git diff --stat android/ 为空，确认手机端零改动。
