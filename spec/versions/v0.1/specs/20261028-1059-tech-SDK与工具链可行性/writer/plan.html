1. 概述

当前没有Android或PC业务工程。本Spec验证后续WebRTC研究的构建前置：依赖有明确来源，最小APK能重复构建，PC实验服务能启动，静态检查和设备实测分别记账。

  • 纳入：工具链与来源锁定、最小Compose APK、只含健康检查的TypeScript服务、验证入口与文档。
  • 边界：本Spec不实现配对、TLS、二维码、摄像头/麦克风采集、信令、OBS媒体接收、便携打包或产品交互。

3.3 数据结构

interface ToolchainLock {
  schemaVersion: 1;
  android: {
    minSdk: 29; compileSdk: 36; targetSdk: 36; buildTools: "36.0.0";
    jdkMajor: 17; agp: "8.13.2"; gradle: "8.13"; kotlin: "2.3.10";
    composeBom: "2025.10.01"; activityCompose: "1.11.0";
    testRunner: "1.7.0"; testJunit: "1.3.0";
    gradleDistributionSha256: string; gradleWrapperSha256: string;
    commandlineToolsUrl: string; commandlineToolsSha1: string;
  };
  node: { version: "24.18.0"; npm: "11.16.0"; typescript: "6.0.3"; nodeTypes: "24.10.1" };
  webrtc: {
    coordinate: "io.github.webrtc-sdk:android:150.7871.01";
    aarSha256: string; releaseTag: "v150.7871.01"; sourceUrl: string;
    manifestMinSdk: 21; abis: string[]; licenseFiles: string[]; distributionNote: string;
  };
  sources: { component: string; url: string; checkedAt: string }[];
}
interface VerificationReport {
  schemaVersion: 1; runId: string; verifiedAt: string; sourceSha: string;
  dirty: boolean; workingTreeDiffSha256: string | null;
  commands: {
    command: string; exitCode: number | null;
    stdoutPath: string | null; stderrPath: string | null;
    startedAt: string; finishedAt: string | null;
  }[];
  checks: { id: string; status: "pass" | "fail" | "not-run"; reason: string }[];
  environment: {
    jdkVersion: string | null; nodeVersion: string | null; sdkPackages: string[];
    deviceChecked: boolean; deviceSummary: string | null;
  };
  artifacts: { path: string; sha256: string }[];
}

以上字段均必填；仅显式联合null的字段可空。时间为ISO8601，哈希为完整小写十六进制；数组无项时为空数组。未结束或未启动的命令exitCode为null且相应检查不能pass；未探测设备时deviceChecked=false、deviceSummary=null。sourceSha记录HEAD；有未提交修改时dirty=true并附工作区差异哈希，不能把HEAD当作已覆盖未提交实现的证据。

结构字段、类型、可空与默认
HealthResponseservice:string固定artemis-receiver；status:string固定ok；version:string固定0.1.0-dev；均不可空、无时间戳
ErrorResponseerror:string，枚举not_found或method_not_allowed；不可空
ReceiverConfighost:字面量127.0.0.1不可空；port:number默认3000，0表示由OS分配端口
ToolchainLockschemaVersion:number=1；android/node/webrtc:对象不可空；每项版本、来源URL、校验算法/值、许可证索引；没有运行验证不写通过
VerificationReportschemaVersion:number=1；runId:string；verifiedAt:ISO字符串；sourceSha:string；commands:数组（command、exitCode、stdout/stderr路径）；checks:数组（id、status=pass/fail/not-run、reason）；environment:脱敏对象

scripts/verify-native-libs.py --aar PATH --apk PATH --report PATH 至少提供aar或apk之一；返回0表示检查项通过、1表示输入或校验失败。对64位库检查PT_LOAD及存在的GNU_RELRO段末端，记录32位ABI；APK ZIP对齐另外运行官方zipalign。脚本不得把静态检查写成设备运行通过。

scripts/bootstrap-android-sdk.ps1 [-SdkRoot string] [-DownloadOnly] 只在指定根及其临时子目录操作；验证官方包清单后展开CLI工具。许可证未接受时明确退出并说明缺项，不以自动yes接受。scripts/verify-toolchain.ps1 [-SdkRoot string] -ReportPath string 检查JDK17、Node24、SDK平台和构建工具，返回0或非零并输出结构化缺项。代理配置仅用于当前进程/本机未跟踪配置，不提交或更改系统代理。

6. 风险和依赖

  • SDK尚未安装；首次许可证接受是环境前置。无法获取官方包或用户未接受许可时停在环境缺项，不替换来历不明的安装包。
  • 固定的版本组合已核对来源和兼容区间，真实Gradle解析、D8编译及运行尚未完成；发生实质选型变更时修订报告并重过gate-2。
  • 本Spec可判定构建/来源/服务层验收；无设备时JNI、Android10安装和16KB运行只能列未实测，后续链路与版本验收不能沿用为通过。
  • GitHub/Maven AAR不是同一容器哈希；Java版本头处理有来源依据，实施时只用固定Maven分发并保留处理说明。
