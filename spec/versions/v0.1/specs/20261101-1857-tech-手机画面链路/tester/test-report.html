4. 关键断言明细

TC-05 画面

OBS 画布显示的是手机摄像头拍到的房间：木质柜体、窗帘、以及一块正显示本项目的显示器。说明数据来自真机相机而非合成色条。现场截图已按用户要求删除，仅保留文字记录与共享内存探针数据。

TC-06 帧率

3 秒内共享内存帧号 810 → 899，约 29.7 fps
OBS 状态栏显示 30.00 / 30.00 FPS

端到端延迟未实测：缺少可靠的同屏时钟参照，未用估算值代替实测。

TC-07 / TC-08

断流前 frameIndex=1935 → 断开 5 秒后 1939（写入停止）
重连前 1939 → 重连后 2354（恢复写入）

TC-09 回滚

停解码进程前 writeIndex=5080 frameIndex=2539
停解码进程后 writeIndex=5080 frameIndex=2539（完全静止）

原因是 OBS 侧的过滤器仍持有共享内存映射，映射不会随写入进程退出而消失，因此画面停留而非回退到合成色条。计划第 9 节写的「停止解码进程即回到合成画面」与实现不符，需修订描述。
