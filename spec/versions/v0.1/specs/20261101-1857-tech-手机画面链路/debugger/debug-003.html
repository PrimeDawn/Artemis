缺陷诊断：画面频繁闪烁色条

类型 debug 编号 debug-003（I-006） 角色 spec-debugger 分支 tech/spec-20261101-1857-phone-media ← dev 创建 2026-11-01 修订 r1（2026-11-01）
结论

过滤器读共享内存失败时直接回退到合成色条。写入端每帧都有短暂的「写入中」窗口（writeIndex 为奇数），读取端撞上就闪一帧色条，因此闪烁频率与帧率相当。

1. 现象

OBS 中手机画面正常，但高频穿插短暂色条，观感为强烈闪烁；手机端与解码进程无异常，帧号持续递增。

2. 根因

FrameSource::FillFrame 的逻辑是：读到有效帧就输出，读不到就调用 RenderBars。而 TryReadShared 在这些情况下返回失败：

  • writeIndex 为奇数（写入端正在写）
  • 两次读取 writeIndex 不一致（读到一半被写）
  • 映射尚未建立

30fps 写入下，每次写入都会经历一个奇数窗口，读取端按 30fps 轮询，撞上就渲染一帧色条，于是与帧率同频闪烁。

3. 修复方案

读取失败时不再立刻回退色条，而是复用上一帧；只有从未成功读到过任何一帧时才回退到合成色条（即解码进程从未启动的场景）。
