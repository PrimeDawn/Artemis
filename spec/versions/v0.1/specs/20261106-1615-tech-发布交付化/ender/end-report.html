8. 遗留风险与后续

未签名带来的分发不确定性

Smart App Control 开启的机器（Win11 全新安装默认开启）可能拦截新构建的安装包，用户需自行关闭该功能。根治只能靠代码签名证书（零预算下不做）。已写入 README「已知限制」。

release keystore 只在本机

android\artemis-release.jks 与 android\signing.properties 均已 gitignore 且只存在于本机。丢失后无法对已安装的 APK 做覆盖升级，必须备份。

音频真实出声未验证

按 D-013 排入 v0.1.1；本轮只验证了「未装 VB-CABLE 时明确提示且画面不受影响」。

Beta 与已知边界

仅 720p30 单档；端到端延迟仍未测量；真实手机换 IP 未测。
