TC-05 / TC-06

OBS 以保存的场景集合启动，直接恢复出设备源并显示实时画面，说明设备 ID 能被 OBS 正确解码、过滤器能被创建并出流。

TC-07 帧更新

间隔数秒的两张画布截图按步长 4 采样比较，204 个采样点像素不同，差异区域集中在画面区（白块位置随时间移动）。

TC-08 无 producer

终止 synthetic-producer.exe 后，画布保持最后一帧（两张截图 SHA-256 完全一致），OBS 无报错、无设备丢失提示。**与测试计划写的「输出黑帧」不同**：实现选择保留最后一帧，因为共享内存仍映射着上一帧。这是行为差异，不是缺陷，但计划需要按实际更新。

TC-09 录制回放

录制区间 16:14:27 → 16:15:08（41 秒），文件 28.14 MB。用 WPF 解码录像取第 5 秒画面，分辨率 1280×720，可见色条与白色方块。

TC-10 反注册

反注册后：total devices: 1（仅 OBS Virtual Camera）
重注册后：total devices: 2（含 Artemis Camera）
