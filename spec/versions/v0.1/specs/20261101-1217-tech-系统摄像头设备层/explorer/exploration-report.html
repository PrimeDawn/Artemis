结论

DirectShow 源过滤器是唯一能让 OBS 把手机当系统摄像头的路线，最小可枚举实现由「COM DLL + CBaseFilter/CSourceStream + 注册到 VideoInputDeviceCategory」三部分组成；共享内存只承担帧传递，先做合成帧即可验证整条链路。

2. 参考实现分析

akvirtualcamera 是 Mac/Windows 双平台虚拟摄像头，Windows 侧就是 DirectShow 过滤器。它的结构可以直接借鉴，但**许可证是 GPLv3，不能复制代码进本项目**，只能参考结构与思路。

2.1 注册方式

windows/dshow/VirtualCamera/src/plugininterface.cpp 用 ROOT_HKEY = HKEY_CLASSES_ROOT、SUBKEY_PREFIX = "CLSID" 直接写注册表，而不是走 IFilterMapper2。这意味着注册与反注册都在 DLL 里手写，regsvr32 只是调用导出函数。

2.2 过滤器组成

层次职责参考文件
类工厂实现 IClassFactory，供 COM 创建过滤器实例VirtualCamera/src/classfactory.cpp
过滤器继承 CBaseFilter，枚举并创建输出引脚BaseFilter/src/basefilter.cpp
引脚继承 CSourceStream/CBasePin，协商媒体类型并填 IMediaSampleBaseFilter/src/pin.cpp
样本实现 IMediaSample 的缓冲区管理BaseFilter/src/mediasample.cpp
媒体类型枚举提供可协商格式列表BaseFilter/src/enummediatypes.cpp

2.3 帧传递

参考实现把帧传递抽成 VCamIPC（windows/VCamIPC/src/ipcbridge.cpp），由独立的 Manager/Service 进程写帧，过滤器从共享内存读。这与我们计划的「producer → 共享内存 → 过滤器」一致。

2.4 像素格式

参考工程的测试程序按 MEDIASUBTYPE_RGB32（32bpp）与 MEDIASUBTYPE_RGB24（24bpp）判断（windows/dshow/Test/src/main.cpp:428）。RGB32 对齐最简单，适合首版；NV12 更省带宽但要处理 stride 与色度平面。

3. 最小实现组成

模块内容验收相关性
COM DLLDllGetClassObject、DllRegisterServer、DllUnregisterServer没有它无法注册
类工厂 + 过滤器CLSID 固定，注册到 CLSID_VideoInputDeviceCategory 并带 FriendlyName = Artemis CameraOBS 列表里出现名字
输出引脚只支持一种媒体类型（RGB32、720p30），拒绝其他请求OBS 能预览

注册脚本regsvr32 安装/卸载，检查退出码可重复安装

4. 共享内存帧协议草案

协议只需要单调递增的帧号与固定布局，先满足「一写一读、不撕裂」。

字段类型说明
magic / versionuint32拒绝旧版本 producer
width, height, strideuint32首版固定 1280×720、stride=width×4
formatuint32枚举值，首版只有 RGB32
writeIndexuint64写入前 +1（奇数=写入中），写完 +1（偶数=稳定）
frameIndexuint64producer 自增帧号，用于画面上的帧号与丢帧检测
timestampUsuint64producer 侧时间戳
frame[]byte双缓冲：两块 region 轮换，读者按 writeIndex 判断稳定块

5. 风险

风险影响应对
注册写 HKCR 需要管理员regsvr32 失败脚本显式检查退出码并提示以管理员运行
GPLv3 参考代码许可证污染只参考结构，不复制源码；本 Spec 自写最小实现
OBS 枚举缓存注册后 OBS 列表不刷新验收时重启 OBS；必要时检查 CLSID_VideoInputDeviceCategory 下条目
VS Build Tools 安装未完成无法编译等待 winget 完成；失败则改用离线安装器
DirectShow 头文件与 BaseClasses缺少 streams.hWindows SDK 不默认带 BaseClasses；首版不使用 BaseClasses，直接实现 IBaseFilter/IPin 最小集合，或引入 Sample 源码并核对许可

6. 建议实施顺序

  1. 先确认工具链装好：cl 可运行、streams.h 可包含
  2. 写最小 DLL：类工厂 + 过滤器 + 一个输出引脚，内部产生色条
  3. regsvr32 注册，用 OBS 验证「列表出现 Artemis Camera 且有画面」
  4. 加入共享内存读取，producer 独立进程写合成帧（色条 + 帧号）
  5. 验收：OBS 录 30 秒回看有画面，含帧号递增

7. 待确认

  • 首版像素格式：RGB32（简单）还是 NV12（省带宽）。建议 RGB32，后续接媒体链路时再评估
  • 分辨率/帧率是否固定 720p30，还是允许 1080p 协商
  • 是否需要 32 位过滤器（当前判断：不需要）
