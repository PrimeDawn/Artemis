结论

「从零复现」当前做不到：一键启动脚本把数据目录和 OpenSSL 路径写死在本机，换台机器就起不来；这是本 Spec 必须先消除的机器绑定。 延迟可以测（同框计时），但音画偏差本轮测不了——音频没有进 OBS 的通道（虚拟声卡按 D-013 留 v0.1.1），只能做 PC 端时间戳层面对齐分析并如实标注。

4. 从零复现的步骤草案

  1. 构建：native/build.ps1、receiver npm ci && build、gradlew assembleDebug；记录版本与哈希。
  2. 注册过滤器：native/register.ps1 register（需要管理员）。
  3. 清空信任：删除 ARTEMIS_DATA_DIR 下身份与信任文件，模拟新用户。
  4. 启动：解码进程 + 接收服务（控制页 127.0.0.1:3000/control）。
  5. 手机：卸载后重装 APK → 打开 App → 电脑控制页单击手机 → 手机上点「允许并记住」（人工步骤）。
  6. OBS：添加「视频采集设备」选 Artemis Camera，录 30 秒回看。
  7. 记录：分辨率、帧率、连接耗时、控制页音频状态文案。

5. 测量方法

5.1 端到端延迟（可测）

同框计时：手机屏幕显示毫秒计时器，外部相机（另一台手机）同时拍到手机屏幕与 PC 上 OBS 预览；在同一帧里读两个时间差即总延迟。三段分解（采集编码、网络、解码呈现）用日志时间戳近似，报告中只把同框读数当结论。

5.2 音画偏差（本轮受限）

端到端偏差需要 OBS 同时拿到画面与声音；音频进 OBS 依赖虚拟声卡，按 D-013 留 v0.1.1。本轮只能：从手机端采集的音频 PTS 与视频 PTS 计算时间戳层面的对齐关系，并明确标注「不是端到端实测」。
