方案结论

先拆掉两处机器绑定（数据目录、OpenSSL 路径），否则「从零」不成立；再做一次完整复测并记录环境、帧率、连接耗时与同框延迟读数。 音画偏差本轮只做时间戳同源的设计核对并如实标注未实测，端到端数值等 v0.1.1 的虚拟声卡。

1. 目标与范围

项内容
目标在一台按文档操作就能复现的前提下，走完「全新安装 → 配对 → OBS 看到手机画面并录出 30 秒」，留下环境、帧率、连接耗时与端到端延迟的实测记录与研究结论。
范围内①启动脚本与文档的机器绑定消除；②从零安装流程；③真机复测与录制回看；④延迟同框测量与粒度说明；⑤音频提示与视频不受影响；⑥依赖与许可证清单核对；⑦研究结论与复现步骤。
范围外音频端到端出声与音画偏差数值（D-013 → v0.1.1/v0.1.2）、安装包打包（release-package）、跨品牌机型、实际断公网、长时段连续运行。

2. 消除机器绑定

文件现状改法
tools/start-artemis.ps1 数据目录与 OpenSSL 路径写死（tools/start-artemis.ps1:9-10） 改为参数：-DataDir（默认 $env:LOCALAPPDATA\Artemis\data）、-OpenSslPath（默认依次探测 Get-Command openssl → Git 安装路径 → 失败并给出可执行指引）；-LanIp 保留自动探测并允许覆盖。
docs/pairing-local-run.md 示例里写死本机路径 改成参数说明与默认值说明，明确哪些是机器相关、哪些可移植。
native/register.ps1 待核对是否含绝对路径 如同问题一并参数化；过滤器注册仍需管理员，保持显式提示。

3. 从零复现流程

  1. 构建三个产物并记录版本与哈希：native/build.ps1、receiver 的 npm ci && npm run build、android 的 gradlew assembleDebug。
  2. 注册 DirectShow 过滤器（管理员，native/register.ps1 register）。
  3. 清空数据目录（身份、信任、选择），模拟新用户。
  4. 启动接收服务与解码进程；记录控制页地址。
  5. 手机卸载重装 APK → 打开 App → 控制页单击手机 → 手机上点「允许并记住」（人工步骤 1 次）。
  6. OBS 添加「视频采集设备」→ 选 Artemis Camera → 录制 30 秒 → 回看确认。

4. 测量方法

指标方法记录方式
分辨率 / 帧率OBS 设备属性与录制文件 ffprobe；同时抓取手机端编码日志的帧计数与时间差数值 + 采样区间
连接耗时控制页发起连接到 sessionId 出现的墙钟差数值（含人工点按环节单独标注）
端到端延迟同框计时：手机毫秒计时器 + PC 上 OBS 预览同帧，外部相机拍摄后读同一帧的两个时间读数 + 相机帧率换算的量化粒度
音频状态未装虚拟声卡时控制页文案、视频是否照常文案原文 + 录制片段
音画偏差本轮只核对「音频与视频 PTS 同源设计」；端到端拍手/口型测试留 v0.1.1标注未实测，不填数值

5. 交付物

  • 验证记录：构建哈希、环境清单、帧率与延迟读数、录制回看结果。
  • 复现说明：按本方案步骤可重跑的简短文档（不重写 README，README 归 release-package）。
  • 依赖与许可证清单核对结果（FFmpeg GPL shared、Opus、OkHttp、Compose 等）。
  • 研究结论：哪些达标、哪些差距、哪些未测及原因。

6. 验收标准

编号通过条件
AC-1启动脚本与文档不再包含本机绝对路径；用临时数据目录可以冷启动成功。
AC-2清空信任后从零完成一次配对（含人工点按），会话建立。
AC-3OBS 能选到 Artemis Camera 并录制 30 秒回看有画面；记录实际分辨率与帧率。
AC-4给出同框延迟读数与量化粒度；不宣称精度高于粒度。
AC-5未装虚拟声卡时控制页提示正确、视频不受影响；音画偏差标注未实测与原因。
AC-6依赖与许可证清单与当前代码一致；既有 Node/JVM 测试与构建通过。

7. 明确不做

  • 不做音频端到端出声与音画偏差数值（v0.1.1/v0.1.2）。
  • 不打安装包、不重写 README（release-package）。
  • 不测跨品牌机型、不实际断公网、不做长时段连续运行。

8. 风险与回退

风险应对回退
手机不在线或授权失效执行前确认 adb devices；失败如实记录并暂停该用例不伪造通过
清信任后配对失败保留旧数据目录备份，失败可回滚复现恢复备份继续其余用例
同框相机帧率过低报告量化粒度，必要时用更高帧率设备标注为低精度读数

9. 实施顺序

  1. 参数化启动脚本与文档，冷启动验证。
  2. 清数据、重装 APK、完成从零配对。
  3. OBS 采集与 30 秒录制回看，记录分辨率/帧率。
  4. 连接耗时与同框延迟测量。
  5. 音频提示与音画偏差标注。
  6. 许可证清单核对与既有测试回归。
