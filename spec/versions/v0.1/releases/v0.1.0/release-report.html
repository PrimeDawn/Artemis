4. 变更说明与数据迁移

数据迁移：无。v0.1 是首次对外发布，不存在旧版本数据。开发期的 %LOCALAPPDATA%\Artemis\data 可保留（身份与信任），也可删除后重新配对。

运行时依赖变化：不再需要用户安装 Node.js、Git for Windows 或 OpenSSL——安装包自带 runtime\node.exe，证书在进程内签发了。

用户需知：

  • 音频需要用户自备 VB-CABLE（D-012/D-013），未安装时只有画面。
  • Smart App Control 开启的 Windows 11 可能拦截未签名安装包，需自行关闭该功能（README 已写明）。
  • 从旧 debug 签名版升级必须先卸载（签名不同无法覆盖安装），会丢失已保存的配对。
