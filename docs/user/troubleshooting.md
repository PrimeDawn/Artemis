# 常见问题

先确认日志位置：

```
%LOCALAPPDATA%\Artemis\logs\
    tray.log         启动、停止、端口与错误
    receiver.log     配对、连接、媒体通道
    decode-host.log  画面解码与音频输出
```

## 托盘图标不见了

- 打开任务管理器，看有没有 `Artemis.exe`。没有就重新从开始菜单启动。
- 有进程但看不到图标：Windows 会把新图标折叠进「^」里，展开看看。

## 浏览器里打不开控制页

- 地址是 `http://127.0.0.1:3000/control`，必须用 `127.0.0.1`，不要用 `localhost`。
- 打不开时看 `tray.log`：如果写着端口被占用，说明 3000 端口被别的程序占了。关掉那个程序，或在 `Artemis.exe` 同目录建一个 `config.json` 换端口：

```json
{ "controlPort": 3001, "tlsPort": 3444, "mediaPort": 3451 }
```

## OBS 里找不到 Artemis Camera

按顺序排查：

1. **OBS 是否以管理员身份运行？** 过滤器的注册信息属于当前用户，管理员身份运行的 OBS 看不到它。关掉 OBS，用普通身份重新打开。
2. **过滤器是否注册成功？** 在「运行」里执行 `regedit`，看 `HKEY_CURRENT_USER\Software\Classes\CLSID\{7E1F3A10-2C4B-4D8E-9A55-3F0C1B7D9E21}` 是否存在。不存在就重新运行一次安装包（安装会重新注册）。
3. **是否重装过？** 重装后 OBS 里旧的设备项可能失效，删掉旧的采集源重新添加一次。

## 画面全黑或没有画面

- 手机 App 必须在前台且未锁屏；切到后台会暂停推流。
- 看 `decode-host.log` 有没有解码错误。
- 手机与电脑要在同一个局域网，且电脑防火墙允许 Artemis 通过专用网络。
- 手机断开后 OBS 会保留最后一帧，重新连上后约 6 秒恢复。

## 手机连不上电脑

- 控制页里能不能看到手机？看不到说明发现阶段就没通，检查两台设备是否在同一网段、路由器是否开了「客户端隔离（AP 隔离）」。
- 手机端如果之前拒绝过，需要在 App 里重新发起连接。
- 公司或校园网络常禁止设备互访，换到家用路由器或手机热点试试。

## 有画面但没有声音

Artemis 需要你自备虚拟声卡。见[音频说明](audio-vbcable.md)。

## 提示「未检测到虚拟声卡」

同上：没有安装 VB-CABLE 时这是预期提示，画面功能不受影响。

## 卸载后 OBS 里还留着设备项

卸载会注销过滤器，但 OBS 的采集源配置还记着旧的设备名。在 OBS 里删掉那个采集源，重新添加即可。

## 系统提示「智能应用控制已阻止此应用」

Windows 11 的 Smart App Control 会拦截没有数字签名的程序。Artemis 目前没有代码签名证书。要运行它，需要在「Windows 安全中心 → 应用和浏览器控制 → 智能应用控制」里关闭该功能（注意：关闭后无法再开启，除非重装系统）。不想关闭的话，本项目目前没有其他办法绕过。

## 安装包提示「未知发布者」

同样是缺少代码签名证书导致的，不影响安装与使用。
