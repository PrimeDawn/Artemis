# 项目偏好

- 产品目标与一期边界以根目录 `产品规划.md` 为准。
- 优先稳定、易连接和可持续使用；一期无账号、付费订阅、云端信令或媒体转发依赖。
- 安卓使用原生 Kotlin/Compose；电脑侧面向 Windows + OBS；共仓维护连接协议。
- 默认 720p/30 fps，最低 Android 10；首个重点验收设备为 S24/Android 16。
- 采集必须由用户主动开始，明确显示相机、麦克风、连接状态与停止入口。
- 页面资源离线随包提供；连接错误给出可理解原因和恢复入口。
- 保留高信息密度但清晰的状态反馈，前端视觉由后续设计 Spec 确定。
- 模拟器、规划指标或静态检查不能代替音视频、后台与性能真机验收。
- 长期约束写 rules；设计理由写 knowledge；一次性需求写对应 Spec。
